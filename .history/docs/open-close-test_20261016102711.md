## 分かったこと
- 常駐しているので、起動中は `ddlauncher.exe` が使われていて、ビルドで置き換えられない（`アクセスが拒否されました (os error 5)`）。ビルド前に「終了」ボタンで終了する。
- 最終的な形では、タスクトレイのアイコンに「終了」「設定」を置くのがよい（未実装）。

## 事前に分かっている不安点
- 他アプリが前面にいる状態で開くと、フォーカスが取れない可能性がある（#4）。今回は取れた。
- 起動直後の短い間にフォーカス喪失が来ると、すぐ閉じる。ターミナルから起動した1回目は、18ms後に閉じた。ピン止めアイコンからの起動では起きなかった（#14）。
- Rustの `windows` クレートは、0.61でコンパイルが通った。
