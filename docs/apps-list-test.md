# アプリ一覧（.lnk 収集・アイコン・起動）テスト

最終更新: 2026-10-16 11:10（ストアアプリ・日本語表示名まで確認済み。この段階は完了）

## 実装した範囲
- `%AppData%` と `%ProgramData%` の `Microsoft\Windows\Start Menu\Programs` を再帰的に集める（`.lnk` と `.url`）
- 同名フォルダは1つにまとめる。同じフォルダ内の同名項目は、ユーザー側を優先して1つだけ
- 左の一覧: 見出しは `#`（数字・記号）、A〜Z、最後に「その他」（日本語名など）。フォルダは展開式
- アイコン: `SHGetFileInfoW`（32x32）で取り、PNG にしてディスクにキャッシュ（`%LOCALAPPDATA%\com.fixtan.ddlauncher\icons\`）。取れなければ頭文字の色付きアイコン
- 起動: 項目をクリック → `ShellExecuteW("open")`（.lnk をダブルクリックしたときと同じ）→ メニューを閉じる
- 開くたびに一覧を見直す（30秒以内は見直さない。変わっていたときだけ描き直す）

## 分かっていて未対応のこと
- UWP アプリ（ストアアプリ。電卓、設定など）は `.lnk` がないので出ない。次の段階以降で別途扱う
- 見出しをクリックして頭文字へ飛ぶ画面（Win10 にある）は未実装
- 日本語名の並びは、読み仮名がないため `Intl.Collator('ja')` 任せ。漢字は読み順にならない
- アイコンは 32x32 まで。タイルの大きいアイコンには足りないので、そのとき大きいサイズの取得を足す
- 白黒の古いアイコンは取れず、頭文字になる
- 要確認: `.url`（インターネットショートカット）のアイコン取得

## 最初の動作確認の結果（2026-10-16 10:46）
- ビルドが通り、一覧が出た（392件、13 ms）。本物のアイコンが出る。出ないものは頭文字（Access、Administrative Tools、AivisSpeech、Amazon Photos など）
- 一覧からアプリを選ぶと起動する（問題なし）
- 不具合: 透明度を下げると、見出し（`#`、`A`）の暗い帯だけ不透明で残り、背面が透けない → 見出しの固定表示（sticky）と背景をやめて修正
- 不具合: 設定・ログ欄が一覧と同系色で、透明にすると溶け込んで分かりにくい → 不透明な別色の面＋アクセント色の上線にして修正
- 気づいた点: 頭文字アイコンになるアプリがある。原因は未調査（`.lnk` の先が UWP、または SHGetFileInfoW が汎用アイコンを返している可能性。ログに「アイコン取得に失敗」が出ていれば前者ではない）。`Administrative Tools` が同名で2つ出ている（フォルダと項目）

## 修正: ストアアプリと日本語表示名（2026-10-16 11:10、実装直後・未確認）
Win10 のスタートメニューと見比べて分かった差を直した。
- 差1: ストアアプリ（3D ビューアー、メール、フォト、Microsoft Store など）が出ない → `.lnk` がないため。`shell:AppsFolder` を列挙して、識別子が「パッケージ名!アプリID」のものだけを一覧の最上位に足す（同名の項目が既にあれば足さない）。起動は `ShellExecuteW("shell:AppsFolder\<識別子>")`、アイコンは `IShellItemImageFactory`（48px）
- 差2: フォルダ名・項目名が英語（Accessories、Administrative Tools）→ ディスク上の名前をそのまま出していた。`SHGetFileInfoW(SHGFI_DISPLAYNAME)` で Windows の表示名に置き換える（推測: ディスク上は英語名で、日本語は desktop.ini の指定で表示されている）
- フォルダ構造は、`AppsFolder` が階層のない一覧なので、引き続き `.lnk` の走査から作る
- `AppsFolder` の列挙に失敗しても、`.lnk` だけの一覧は出る（ログに「アプリフォルダの列挙に失敗」）

## 残っている小さな問題（対応は保留）
- 最初の起動で、開いた14 ms後にフォーカス喪失で閉じることがある（11:02:01 のログ）。ピン止めアイコンからは出なかった。対策案: 開いてから約300 ms はフォーカス喪失で閉じない
- 一覧の取得が約1.1秒かかる（起動直後のみ遅れて出る）
- 日本語名の並びは `Intl.Collator('ja')` 任せ（漢字は読み順にならない）
