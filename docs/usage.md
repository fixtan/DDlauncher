# DDlauncher の使い方

（画像を入れる場所は 📷 で示す。スクリーンショットは後で差し込む）

## 1. 起動してタスクバーにピン止めする
DDlauncher はタスクバーのアイコンから開く使い方を想定しています。最初に一度だけ、手動でピン止めします。

1. `ddlauncher.exe`（インストーラーを使った場合は、スタートメニューの「DDlauncher」）を右クリック
2. Windows 11 では「その他のオプションを確認」→「タスクバーにピン留めする」
3. ピン止めしたアイコンを押すと開き、もう一度押すと閉じます

📷 ピン止めの手順（右クリック → ピン留め）

ピン止めを外しても、タスクトレイのアイコンから使えます。

## 2. 基本の操作
- **開く / 閉じる**: タスクバーのアイコン、タスクトレイのアイコン（左クリック）、ホットキー
- **アプリを起動**: 左の一覧をクリック。または検索（下記）
- **タイル**: 一覧のアプリを右クリック →「スタートにピン留めする」、または右のタイル領域へドラッグ
  - タイルはドラッグで動かせます。右クリックでサイズ変更・ピン留めを外す
- **ファイル名を指定して実行**: 左端の 🚀 を押して、`regedit` `cmd` `shell:startup` `C:\Tools` などを入力して Enter（Win+R 相当。`%USERPROFILE%` なども使えます）。Ctrl+Shift+Enter で管理者として実行。前回の入力が残るので、もう一度 Enter だけで実行できます。失敗したときは入力を残して理由を出します。複数行のコマンドや、出力を読みたいコマンドは、今までどおりブックマークの「コマンド」を使います
- **ウィンドウを閉じたら**: 検索・実行の入力は片付いて、開き直すと最初の一覧に戻ります
- **管理者として実行 / ファイルの場所を開く**: 一覧のアプリ、またはタイルを右クリック。ストアアプリには出ません（実体のファイルがないため）。「管理者として実行」は exe・ショートカット・バッチだけ。ショートカットの場合、「ファイルの場所を開く」は指す先のファイルをエクスプローラーで選んだ状態で開きます
  - エクスプローラーの exe・フォルダ・ショートカットを、タイル領域にドロップして追加することもできます
- **閉じる**: Esc、または外側をクリック（設定で変更可）

📷 画面全体（アプリ一覧・タイル・左端の列）

## 3. 検索
🔎、Ctrl+S（または Ctrl+F）、または何も開いていない状態で文字キーを打つと、検索欄が開きます。
- 先頭が一致するものが上、途中が一致するものが下に出ます
- 空白で区切ると、すべてを含むものだけ残ります
- ↑↓ で選び、Enter で起動。Esc で閉じます
- 日本語を打つときは、🔎 か Ctrl+S で開いてから打ってください

## 4. ブックマーク（🔖）
アプリ・フォルダ・コマンドを登録しておくリストです。グループ（フォルダ）に分けられます。
- 追加: 🔖 にファイル・フォルダをドロップ／一覧を右クリック →「ブックマークに追加する」／設定 →「ブックマーク」
- コマンド: 複数行で書けます。作業フォルダも指定できます。
  ```
  cd C:\Users\me\project
  npm run build
  ```
  新しいコンソールが開いて実行されます（設定で、終わったら閉じるようにもできます）

📷 ブックマークのリスト

## 5. 左端のアイコン列
よく使うものを並べておく列です。ファイルやフォルダをドロップして追加します。右クリックで外す・並べ替え。
下の 🔖・🔎・⚙ は固定です。

## 6. ホットキー
設定 → 一般 →「ホットキー」の欄をクリックして、キーの組み合わせを押します（例: Ctrl+Alt+Space）。
どのアプリが前面でも、押すと DDlauncher が開き（マウスのあるモニターに出ます）、もう一度押すと閉じます。
「ホットキーで開いたら、検索欄から始める」にチェックがあると、押してすぐ打って Enter で起動できます。
Win キーを含む組み合わせは使えません。

## 7. 自動起動
設定 → 一般 →「Windows 起動時に自動で起動する」。ウィンドウは出さず、トレイに常駐します。

## 8. バックアップ
設定 → 一般 →「バックアップ」。設定・タイル・左端・ブックマークを1つの JSON に書き出し／読み込みます。
読み込む前の内容は、各ファイルの `.bak` に残ります。別のPCに移すときは、同じ場所に無いアプリは動きません。

## 9. うまくいかないとき
- 設定 →「ログ」に、開閉や起動の記録が出ます。不具合の報告にはこれを添えてください。
- 設定ファイルの場所は README の「データの場所」を参照してください。
