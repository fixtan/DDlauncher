# Win10風スタートメニューランチャー 要件メモ（2026-10-16）

## 目的・背景
- ExplorerPatcher (EP) はWindows更新のたびにスタートメニューが壊れ、再インストールでWin10タイル配置も全消失した。
- Explorer内部に依存しない独立アプリとして、Win10のタイル型スタートメニューを自作する。
- 方針: 「みんなが知っているWin10のあのスタートメニュー」をそのまま再現し、その上で便利な機能を足す。迷わないことを優先する。

## 開発方針
- 新規リポジトリでゼロから作成（lain-lab のルートは汚さない）。過去の自作コードは自由に再利用してよい。
- 技術は Tauri + Web UI を第一候補（Lookover / DISC.TOC / shotkey と同系統）。
- アニメーションは不要。動けばよい。挙動が正しいことを最優先する。

## 画面レイアウト（Win10そのまま＋左端を拡張）
- 左端の細い列（上から）: ユーザー追加スペース → 🔎検索 → ⚙設定。電源アイコンは置かない。
- 左: 旧式のインストールアプリ一覧（頭文字見出し、フォルダ展開、最近追加したもの）。
- 右: タイル領域（グループ見出し付き）。

## タイル仕様
- サイズは小・中・大。小は中サイズの枠に4つ入り、その4つがグループになる（browser 4つ、など）。
- Win10と同じく、空けた隙間は保持する（マス座標で配置）。
- ドラッグで挿入すると、置いた位置のタイルは下へ押し下げられる。押し出しの細かいルールは実機のWin10挙動を観察して確認する（未確認）。
- 満杯グループへの追加、空グループの扱いなどは仕様を先に決める。
- アニメーションなし。

## 左端のユーザー追加スペース
- 登録できるもの: .lnk、`ms-settings:` や `control.exe` のようなコマンド、フォルダ。
- 例: インストールアプリ一覧、コントロールパネル、電源管理など、よく使うものを自分で追加。

## 検索（コマンドランチャー兼用）
- 🔎を押すと横に入力欄が出る。入力で候補が絞られ、Enterで起動。
- 前方一致を上、部分一致を下に並べる（例: `s` で shotkey / SideQuest / Steam）。
- 検索対象は左の一覧と同じ .lnk リスト。上下キーで選択可能。

## 呼び出し方
- タスクバーにピン止めして、スタートボタンの隣に置く。クリックでメニューが上に開く（Win11のスタートボタンとも共存）。
- 常駐させ、ピン止めアイコンの再起動（2回目の起動）を単一インスタンスで受け取り、表示/非表示を切り替える方式を想定（要検証）。
- フォーカスが外れたら閉じる。ただし「閉じるためにアイコンを押したら再度開く」ちらつきを防ぐ処理が必要。
- 位置はタスクバー直上（左下側）。実際の置き場所は試して決める。
- 補助としてグローバルホットキーも追加できる（任意）。

## 表示位置
- 左・中央・右（下側）に加えて、左上・中央上・右上も選べるようにする。設定で切り替え。
- モニターの作業領域を基準に配置する。

## 見た目・テーマ
- UIはHTML/CSSなので、装飾は自由。CSS変数＋テーマ用JSONでテーマ化する。
- 背景画像、透過（ウィンドウ透過、可能ならぼかし）に対応したい。透過・ぼかしはWindowsで挙動に癖があるため要検証。

## データ・保存
- アプリ一覧の元: `%AppData%\Microsoft\Windows\Start Menu\Programs` と `C:\ProgramData\Microsoft\Windows\Start Menu\Programs` の .lnk を再帰で収集。
- アイコンは .lnk から抽出してPNGでキャッシュ。UWPアプリ（フォト、Storeなど）は初期は対象外、後で対応。
- タイル配置・グループ・左端設定は自前のJSONに保存する。一時ファイルに書いてから置き換える方式で、書き込み中の破損を防ぐ。バックアップを数世代残す。

## 作る順番
1. .lnk収集、アイコン抽出＋キャッシュ、起動、左の一覧（ここまででスタートメニューの代わりになる）
2. 右のタイル表示、ドラッグ配置（隙間保持）、小・中・大、小4つのグループ
3. 左端アイコン列、検索
4. JSON保存の安全化、バックアップ
