## 追加: エクスプローラーからのドロップ（2026-10-16 11:35、実装直後・未確認）
スタートメニューにない単体の exe、フォルダ、ショートカットなどを、エクスプローラーからタイル領域へドロップして追加する。
- ドロップ位置: タイル領域の中なら、その場所に（最初の1件）。外なら空いている場所へ。複数なら残りは空いている場所へ
- 名前: exe・lnk・url・bat・cmd・com は拡張子を外した名前。フォルダはフォルダ名。それ以外の書類などは拡張子つき
- 同じパスは大文字小文字を区別せず、追加しない（ログに「既にピン留め済み」）
- 起動: exe は、そのフォルダを作業フォルダにして `ShellExecuteW("open")`（管理者権限が必要な exe は UAC が出る想定）
- ドラッグ中、グリッドを見せる
- **フォーカス喪失で閉じる処理の変更**: エクスプローラーのファイルを掴むと、DDlauncher がフォーカスを失って閉じてしまい、ドロップ先がなくなる。そこで、マウスボタンを押したままフォーカスが外れたときは、ボタンを離すまで待ち、離したあと250 ms 以内にこのウィンドウへのドロップがあれば閉じない。なければ閉じる（外側クリックで閉じる動作が、約0.3秒遅れる可能性あり）。ドロップを受けたら、こちらへフォーカスを戻す

## アイコンの矢印と大きさ（2026-10-16 11:50、実装直後・未確認）
ユーザーの指摘: ショートカット（.lnk）のタイルに矢印が付く。アイコンの大きさがタイルの大きさに応じて変わった方が自然。
- 事実: .lnk は、ドロップしたパスそのもの（.lnk）をタイルに登録している。exe そのものではない。.lnk には引数・作業フォルダ・管理者実行などの指定が入っているので、そのまま登録するのが正しい。代わりに、.lnk を移動・削除するとタイルが起動できなくなる
- 事実: アイコンに矢印が付いていた。実装時のコメントに「矢印は付けない」と書いたのは、私の想定が外れていた（スタートメニューの一覧にも付いていた）
- 修正: .lnk の中身を読み（`IShellLink`）、アイコンの指定があればそのファイルから、なければ指す先（exe など）から取る。指す先が取れなければ従来の方法（矢印付き）に戻る
- 大きさ: 取得するアイコンの大きさを、タイルに合わせる。小=32px、中・横長=48px、大=96px。一覧は32px。タイルのサイズを変えると、取り直す
- キャッシュは大きさごとに別。抽出方法を変えたので、古いキャッシュは使われない（初回の表示で全アイコンを取り直す）

## 追加の不具合: 単体 exe のアイコンが頭文字になった（2026-10-16 11:55）
症状: ドロップで追加した単体アプリ（hotrun-app）のアイコンが「H」の頭文字になった。以前（矢印付きで）は出ていた。
ログ: 起動直後に `アイコン取得に失敗: SHGetFileInfoW がアイコンを返さなかった` が1件だけ。
- 確定した不具合（修正済み）: 失敗した取得（null）を JS が覚えていて、アプリを再起動するまで取り直さなかった。そのため、ドロップし直しても「H」のまま・ログにも新しい失敗が出なかった
- 原因はまだ特定できていない: ログからは分からない。**可能性**（未検証）: (a) hotrun-app のファイルが移動・再ビルドで消えた／置き換わった、(b) 新しい取り方が失敗し、従来の方法も失敗した
- 診断を足した: ファイルが存在しなければそう返す。失敗時は、試した方法ごとの理由（lnkの指す先、シェルの画像、アイコン資源、従来の方法）をまとめて、パスと大きさ付きでログに出す
- 取り方を足した: exe・dll・ico は、シェルを通さず、ファイル自身のアイコン資源から直接取る方法を追加
- アイコンの大きさを拡大: 小40px / 中・横長64px / 大128px

## 不具合メモ: ログタブでダイアログが画面外へ下がる（2026-10-16 修正）

- 症状: ログの行数が増えると、設定ダイアログが下へずれて画面外に出る。
- 原因: ダイアログを格子（grid）で中央に置いていて、箱の高さを % で指定していた。ログ（行数分の高さ）が格子の高さを押し広げ、その中央に置かれた箱が下へずれた。
- 対処: 箱の高さを vh 指定にし、ログ欄は絶対配置にして、内容の高さがダイアログの高さに影響しないようにした。
- 確認: Chromium（Playwright）で、ログ 60 行のときの位置を計測。修正前 top=900、修正後 top=130（高さ 440）。
- 教訓: jsdom ではレイアウトを計算しないので、この種の不具合は見つけられない。見た目の不具合は実ブラウザで確認する。

## 不具合メモ: 長いパスで設定ダイアログが横にはみ出す（2026-10-16 修正）

- 症状: 「ブックマーク」「左端」タブで、長いパスの項目があると、横スクロールバーが出て、✕ ボタンやフォームが右に切れる。
- 原因: タブの中身を grid にしていて、列の幅が内容（長いパス）に引っ張られて広がった。
- 対処: 列を `minmax(0, 1fr)` にして、内容に関係なくダイアログの幅に収める。
- 確認: Chromium で、長いパス（約 170 文字）を入れて、scrollWidth = clientWidth（はみ出しなし）。
